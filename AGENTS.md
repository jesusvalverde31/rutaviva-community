# Reglas de RutaViva Community

- Trabaja solo dentro de este proyecto salvo actualización documental central expresamente aprobada.
- Conserva `rutaviva-local` intacto; es una referencia histórica, no una dependencia.
- No edites `.codex/agents/*.toml`.
- Node.js 24 o superior, JavaScript moderno, HTML semántico y CSS propio.
- No instales dependencias, conectes proveedores, despliegues ni publiques sin un bloque aprobado.
- No escribas secretos en Git, documentación, logs, pruebas o comandos.
- Navegador, API y base de datos se separan; el navegador no accede directamente a PostgreSQL.
- Ninguna aportación comunitaria altera rutas antes de moderación y publicación.
- Usa siempre “ruta orientativa”; nunca prometas una ruta segura.
- Distingue PROPUESTO, IMPLEMENTADO, VERIFICADO y NO VERIFICADO.
- Las pruebas usan datos sintéticos y recursos aislados.
- Toda mutación sensible requiere validación, autorización, idempotencia, concurrencia y auditoría.
