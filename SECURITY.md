# Seguridad

Las versiones soportadas son `main` y la última release publicada. Para comunicar una vulnerabilidad usa de forma privada [GitHub Security Advisories](https://github.com/jesusvalverde31/rutaviva-community/security/advisories/new). No abras una incidencia pública.

Incluye el SHA o versión afectada, impacto, reproducción con datos sintéticos y una posible mitigación. No compartas explotación activa, correos, enlaces mágicos, tokens, credenciales, direcciones privadas ni datos personales. El proyecto no promete un plazo de respuesta ni un servicio permanente.
